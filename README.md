# Einrichtung starten

Ein Befehl richtet einen fremden Linux- oder macOS-Rechner vollständig ein:
Werkzeuge installieren, das private Projekt-Repository beziehen, das PDF bauen
und prüfen.

```bash
curl -fsSL https://raw.githubusercontent.com/yrotciv11/srm-vollmacht-start/main/start.sh \
  | bash -s -- yrotciv11/srm-vollmacht
```

Dieses Repository enthält **nur dieses Installationsskript** – keine
Firmendaten, keine Dokumente, keine Zugangsdaten. Das eigentliche Projekt liegt
im privaten Repository und wird erst nach Ihrer Anmeldung geladen.

Die Anmeldung erfolgt über einen Gerätecode: Sie tippen ihn auf einem beliebigen
Gerät mit Browser ein, auch auf Ihrem Handy. Der fremde Rechner sieht Ihr
Passwort nicht.
